                  Pick a symbol to start

                  A symbol is a named piece of your code — a function, a class or a method (like slugify or UserService). The graph puts it in the middle and draws what connects to it.

                  Three ways to pick one: start typing its name in the box above and choose from the list · click a name below · or in Review/Navigate, click a function in a file and press Open ripple view.

                  structural edge (graph) lexical edge (name match) reached by no test test (outer ring)
                  How the graph works

                  A map of who calls what in this repo, built from your code — not from the agent's memory. Each dot is a function or class; each arrow is a call or an import, and clicking it shows the exact line that makes it true.

                  Read by: …

                  Start

                  1. Type a function or class name above the graph (e.g. slugify), or select a symbol in a changed file or in Navigate and press Open ripple view in its inspector.
                  2. Pick a view (below) and press Show.
                  3. Click a dot or arrow for its source. Double-click a dot to re-centre on it.

                  The four views

                  Ripple
                  “If I change this, what else is affected?” The symbol sits in the middle; each ring further out is one more hop of callers. Tests sit on the outer ring.
                  Focus
                  One step each way: who calls it (left) and what it calls (right).
                  Path to…
                  “How does A reach B?” The shortest chain of calls between two symbols.
                  Untested paths
                  The caller chains into the symbol that no test runs — where a change could break something unnoticed.

                  Reading it

                  • solid arrow — the code graph proved this call/import.
                  • dashed arrow — only a name match (a hint, not proof).
                  • amber dot — on a chain no test reaches.
                  • ringed dot — a test.
                  • depth — how many hops out to look. Start at 2; raise it to see further, lower it if the picture gets crowded.

                  Nothing found? The symbol may be spelled differently, or the graph may not cover that language yet — the note under the details says which.
