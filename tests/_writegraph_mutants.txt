M07's survival is worth recording rather than just fixing, because the survivor was honest and the
test was the thing at fault. M07 changes `_binding`'s frame lookup from MEMBERSHIP (`name in
frame`) to TRUTHINESS (`frame.get(name)`), so a binding recorded as "assigned something that is NOT
a constructor" stops halting the outward walk. The input the suite had — a rebind in the SAME
function scope — cannot tell the two lookups apart: either way the walk finds nothing in the outer
frames and returns None. Only a rebind in a NESTED scope, with a live constructor binding in the
enclosing one, separates them; without it the resolver would happily invent an edge from an inner
`s = make_store()` to the outer `s = Store()`'s methods.

So the fix was to BUILD THE INPUT THAT REACHES IT (`by_shadowed.inner` in
`test_the_receiver_rule_resolves_a_constructor_bound_local`), never to delete the rule — and M13
was added at the same time to pin the other way the same invariant breaks: an assignment that fails
to CLEAR a binding, rather than a lookup that fails to STOP at one.
