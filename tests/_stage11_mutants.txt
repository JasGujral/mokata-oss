--------------------------------------------------------------------
Three separate things existed, and the sentence joining them was the one nobody checked:

  * doc 02's 0.0.16 verification sweep — a markdown table whose last column, "Blocking the
    0.0.16 cut?", is TYPED BY A HUMAN from the sweep author's notes. It reported TODELETE-LEAK

  * `scripts/check-tracker-tables.py` — the only mechanical doc gate. It checks table SHAPE
    (cell count against the header) and says nothing about whether a cell is TRUE. A row can be
    perfectly shaped and wholly wrong, which is exactly what happened.

stage derives that claim and then holds the doc to it. It does NOT rewrite doc 02 — it makes the
doc CHECKABLE, the same move check-tracker-tables.py made for shape, applied to what a cell says.

A FALSE-RED FOUND AND FIXED DURING THE STAGE
--------------------------------------------
The first derivation compared entries EXACTLY. Against the real script that produces a false RED
for any path one control covers by a literal and the other by a glob — `.env` is in
`INTERNAL_PATHS` but `--exclude` carries `.env*`; likewise `release-backup-*` and `*.mp4`, which
`--exclude` anchors (`/release-backup-*`) and the guard does not. Eight of the 32 exclude entries
and three of the 27 guard entries differ only in that spelling.

Calling those RED invents a leak that is not there, and a status column that cries wolf is
abandoned exactly as fast as one that lies. Guessing GREEN is the stale-green this stage exists
to remove. So glob-only coverage became a THIRD answer: UNDECIDABLE, naming the pattern, routing
a human to look. B05 grades it.

Also corrected: `--exclude="/$rel/"` (sync-public.sh:52) is built inside a loop over discovered
nested checkouts, so it is not a literal at all. Read as the string `/$rel` it would have put a
path into the covered set that covers nothing. Entries containing `$` are now dropped.

WHAT THIS STAGE DOES NOT DO
---------------------------
* IT DOES NOT REWRITE doc 02's status column into a generated one. Doc 02 carries another lane's
  uncommitted edits in this worktree and could not be touched; and adding a generated file under
  docs/build/ would breach CLAUDE.md's "exactly 9 living docs" rule. What lands instead is
  strictly stronger than a regenerated cell in one respect — a generated column is only as good
  as the last regeneration, whereas this comparison reds on EVERY run — and weaker in another:
  a human still types the cell, and still types it wrong until a test run tells them. Pasting
  `ControlResolution.render()`'s output into the doc remains available and is one edit.
* IT COVERS TWO DOC ROWS (TODELETE-LEAK, NODE_MODULES-LEAK), not the whole sweep table. Those are
  the rows that name mirror-boundary controls, which are the only ones `sync-public.sh` can
  decide. Rows about tracker ticks or CHANGELOG coverage have no control to derive from — they
  would be UNDECIDABLE for a structural reason, and filling them in would be the same guess this
  stage removes.
* IT DERIVES FROM sync-public.sh ONLY. The rsync boundary is one control; `git add -A` in the
  public checkout is another, and NODE_MODULES-LEAK showed the mirrored `.gitignore` silently
  acting as a third. Nothing here reasons about those.
