FOUR REQUIREMENTS, NOT ONE STRING (§7g)
---------------------------------------
"Absent" and "reworded" must not share a representation, so `check_registration_step` grades four
requirements independently and each failure names what went missing:

  registration-step-present               the step exists at all
  names-the-session_save-tool             it names the tool to call
  requires-register-true                  it requires `register` be SET true, not merely named
  positioned-before-the-first-question    it precedes the question-asking instruction

A FIFTH OUTCOME IS NOT A REQUIREMENT and is deliberately not folded into one. The ordering is
relative to an anchor; a document with no question-asking instruction left gives it nothing to be
relative to, so it renders UNGRADABLE with its reason and `ProseReport.ok` is FALSE. "No anchor
found" silently meaning "the order is fine" is the two-meanings defect 0.0.17 spent itself closing
— B04 is the mutant that grades it.
