EXIT CONTRACT's BROKEN state with no way to say so — it shares a representation with "still
running", which is §7g inside the mutation harness itself. Filed as
`MUTATE-SH-NO-TIMEOUT` (doc 84 §2, beside `MUTATE-SH-NO-CONCURRENCY-INTERLOCK` and stage 31's
`MUTANT-BATCH-NEEDS-A-GREEN-BASELINE` — all three are "the harness cannot distinguish did-not-grade
from graded-fine"). B14 was re-spelled to weld paragraphs while still advancing, and REDs.

Both survivors are recorded here rather than quietly re-run, because each was a finding about the
guard and neither would have been visible from the score alone.

  B01 SURVIVED — and the mutation could not have done anything else.
      The filter read `getattr(gate, "backed", False)`. `GateRef` is a dataclass with
      `backed: bool = True`, so **the default was unreachable**: every row in `GATES` carries the
      attribute. Flipping an unreachable default is a no-op, and no test can grade it — doc 85
      §7f, "a clean mutation score can mean the defence is UNGRADABLE", reached from the other
      side (here the redundant half was dead rather than merely duplicative).
      Worse than dead: the fallback said `False` while the field it was defending defaults to
      `True`. Had it ever been reachable it would have silently DEMOTED a real gate — the precise
      failure this stage exists to repair, hiding inside the guard against it.
      FIX: deleted, per the pre-1.0 no-scaffolding rule (CLAUDE.md) — `gate.backed`, one path.
      RE-SPELLED as `if gate.backed` -> `if gate or True`, which now REDs with 9 failures.

  B10 SURVIVED — and it exposed a real hole, not a weak mutant.
      A number written in words that stops resolving is **dropped, not failed**: `_number`
      returns None and the claim vanishes. The anti-vacuity floor stayed green because every fact
      is also stated in digits on some other page, so deleting `five` silently un-graded
      `docs/index.md:26` ("Five of those gates are enforced by a hook") with nothing going red.
      A drop and an agreement had the same representation — doc 85 §7g at the level of a claim.
      FIX: `WORDS_IN_USE` in the test module pins the four spellings the public pages actually
      lean on (`one` ×2, `four` ×12, `five` ×1, `ten` ×1), in BOTH directions — each must still

      reds instead of joining the ungraded set). The literal is declared with its reason: which
      word a writer reaches for has no source to derive it from (§7j).
